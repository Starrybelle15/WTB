# Luxury Bag Review Intelligence Platform

## Overview

The Luxury Bag Review Intelligence Platform is an AI-powered web application that collects publicly available online review content for luxury handbags and performs sentiment analysis to provide customer insights.

The platform enables users to search for a luxury handbag model and automatically generates:

- Overall customer sentiment
- Positive and negative keyword extraction
- Interactive sentiment visualization
- Executive summary of customer opinions

---

## Features

- Search luxury handbag reviews
- AI-powered sentiment analysis
- Keyword extraction
- Interactive dashboard
- Executive summary generation
